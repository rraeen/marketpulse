# Story 02 - Category Listing Page

## Goal

Show a list of published posts for a selected category.

## Status

- Story defined (no implementation yet).

## Developer Tasks

- Build category listing page with pagination or simple list.
- Render post cards with title, excerpt, image, and date.
- Add empty state UI.

## Requirements

- Display title, excerpt, featured image, and publish date.
- Only "Published" posts appear.
- Empty state message if no posts.

## Workflow

GuestUser -> SelectCategory -> CategoryListing -> PostSelect

## Acceptance Criteria

- Draft posts never appear.
- Clicking a post opens the post detail page.
- Empty state is clear and friendly.
