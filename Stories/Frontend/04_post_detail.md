# Story 04 - Post Detail Page

## Goal

Display the full content of a published post.

## Status

- Story defined (no implementation yet).

## Developer Tasks

- Build post detail page and data fetch.
- Render HTML body safely.
- Add navigation and footer to the page.

## Requirements

- Render title, body (rich text/HTML), featured image, category, and publish date.
- Show a consistent layout with navigation and footer.

## Workflow

GuestUser -> PostSelect -> PostDetail

## Acceptance Criteria

- Draft posts are not accessible from public routes.
- Content renders correctly on mobile and desktop.
