# Story 01 - Public Site Shell and Navigation

## Goal

Provide a public-facing shell with navigation to the five content categories and a consistent layout that looks professional.

## Status

- Story defined (no implementation yet).

## Developer Tasks

- Build shared layout (header, footer, nav).
- Add category routes and navigation links.
- Add disclaimer component in footer.

## Requirements

- Responsive layout for mobile/tablet/desktop.
- Navigation links for all categories:
  - Micro-economics
  - Stocks
  - Commodities
  - Investment Market Updates
  - Investment Guidance
- Footer renders legal disclaimers on all public pages.
- Professional financial aesthetic (deep blue/grey/white palette).

## Workflow

GuestUser -> Home -> SelectCategory -> CategoryListing

## Acceptance Criteria

- Navigation links route to correct category pages.
- Layout remains readable at common breakpoints.
- Legal disclaimer text is visible on all advisory pages.
